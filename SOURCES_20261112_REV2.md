## REV2: REPLACEMENT Lyα label check (fit data not swapped)

Eq. 26 (arXiv:2607.27410): DM/rd = 39.32 ± 0.33, DH/rd = 8.600 ± 0.066, ρ = +0.225.

Official file `/workspace/desi_r01/desi_gaussian_bao_ALL_GCcomb_mean.txt` (header `# [z] [value at z] [quantity]`): at z=2.33 the order is DH then DM, unlike the lower-z pairs (which are DM then DH).

- 0-based index 11 (Wolfram 1-based 12): `DH_over_rs` = 8.631545674846294
- 0-based index 12 (Wolfram 1-based 13): `DM_over_rs` = 38.988973961958784

Fit assignment (not swapped):

- `R03/calc/cplmodel_r03.py` lines 7–8: `dNew[11]=8.600; dNew[12]=39.32` and `covNew[11,11]=0.066**2; covNew[12,12]=0.33**2; covNew[11,12]=covNew[12,11]=0.225*0.066*0.33`
- `R03/wolfram/common_R03_fullrs.wl` lines 4–9: `qs={...,"DH","DM"}`; `dNew=ReplacePart[dOld,{12->8.600,13->39.32}]`; covariance `{12,12}->0.066^2, {13,13}->0.33^2, {12,13}->0.225*0.066*0.33`
- The same assignment is repeated in `callfix_LCDM.wl`, `callfix_oLCDM.wl`, `callfix_wCDM.wl`, and `callB0_wbaoonly.wl` (each lines 7–9 or 6–8).

The Python `bao()` function in `cplmodel_r03.py` labels each slot from the official file's quantity column, so index 11 is modelled as DH and index 12 as DM. **The REPLACEMENT fit used the Eq. 26 numbers in the correct slots.** Description text already matched Eq. 26 and was not rewritten except to name the branch as current-information. No REPLACEMENT row is NOT READY for this reason.

## REV2: z_eff (exact evaluation, not interpolation)

Distance values in this pack were computed by evaluating the background model (Laplace `pred` / chain `pred`) at the exact grid z ∈ {0.9, 1.2, 1.5, 1.8}:

- Wolfram: `zE={0.9,1.2,1.5,1.8}` and `pred[mp[qb],z]` in `R03/wolfram/common_R03_fullrs.wl` (prediction block around the `fitm` definition).
- Python: `pred(th, zs=...)` in `R03/calc/cplmodel_r03.py` evaluates `DCh(z)` and `E(z)` at each requested z; the R03 band scripts call it at those four redshifts (and, for CPL documentation only, a denser grid that was not published as the pack's scored nodes).

They were not obtained by linear interpolation between nodes. The R02 source-row abstention text that called for linear interpolation in z between grid nodes is a scoring instruction in the frozen table; REV2 withdraws that instruction. A review-reported interpolation bias (~0.107 in DM/rd, ~0.084 in DH/rd) was not recomputed in this pack and is labelled UNVERIFIED here. No row is marked NOT READY for interpolation.

## REV2: ΛCDM width label and 0.1% systematic floor

The phrase “parameter-only, conditional on the compressed CMB prior and massless-neutrino background” is applied to the flat ΛCDM BAO+CMB rows (CTC-2P-R03, CTC-2B-R03). The 0.1% systematic floor is taken from the r_d fitting formula versus CLASS `rs_d` offset in `R03/calc/class_crosscheck_r03_output.json`:

- `cases.LCDM_REPL_fullrs.rd_formula_vs_CLASS_rs_d` = 0.0008614628473124775 (~0.0861%)
- `cases.wCDM_REPL_fullrs.rd_formula_vs_CLASS_rs_d` = 0.0008658342064646884 (~0.0866%)
- `cases.CPL_PRIM_fullrs_best.rd_formula_vs_CLASS_rs_d` = 0.0008890861536268169 (~0.0889%)

These are the full-r_s cases. The review's “~0.09%” is this offset, rounded; the pack states a 0.1% floor covering it. CTC-1 (BAO-only) widths are labelled parameter-only without the compressed-CMB-prior clause, because that model does not use the CMB prior or the r_d formula in the same way (A = c/(H0 rd) is free).
